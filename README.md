# MySweetPlace

**Ваше уютное местечко в интернете.** [English version](README.en.md)

MySweetPlace — персональное пространство, которое объединяет личную страницу, небольшой блог, портфолио, ссылки и интересы. Это не соцсеть и не конструктор сайтов: у каждого есть своё местечко по адресу `mysweetplace.org/@username`, которое можно постепенно обустраивать, менять и наполнять своей жизнью.

## Что умеет

- **Местечко из блоков.** Введение, ссылки, проекты, записи, «сейчас», стек, интересы, музыка, фото, гостевая книга, соседи, таймлайн и свободный текст. Для каждого блока можно выбрать порядок, видимость, ширину, вид, заголовок и свой акцентный цвет.
- **Кастомизация важнее шаблонов.** 10 готовых тем, шесть цветов, 34 шрифта с кириллицей, фон цветом, градиентом, узором или картинкой, шесть стилей карточек, скругление и ширина страницы. Всё сразу видно в живом предпросмотре редактора.
- **Записи (микроблог).** Markdown, подсветка кода, до четырёх фото и встраивание YouTube, Яндекс Музыки, Spotify, SoundCloud, Apple Music, Rutube, Vimeo и CodePen.
- **Гостевая книга.** Гости оставляют записи, а хозяин может скрывать, закреплять и удалять их, включать премодерацию и ограничивать круг пишущих.
- **Соседи вместо подписчиков.** Соседство не обязано быть взаимным. Соседей можно показать списком или «районом» из домиков.
- **«Отправить меня куда-нибудь».** Случайное местечко без алгоритмов и рекомендаций.
- **Стек.** Каталог почти из 400 языков, фреймворков и инструментов с иконками, плюс свои технологии.
- **Поиск по интересам**, двуязычность (русский основной, английский второй, в том числе для содержимого местечка), снег зимой и гирлянды под Новый год.
- Превью ссылок в мессенджерах и соцсетях благодаря серверному рендерингу.

## Стек

| | |
| --- | --- |
| Бэкенд | Ruby 4.0, Rails 8.1 (API), PostgreSQL + JSONB, Active Storage |
| Фронтенд | TypeScript, Svelte 5, SvelteKit (SSR, adapter-node) |
| Сервер | Ubuntu Server 26.04, nginx, systemd, Let's Encrypt |

```
backend/    Rails API, всё под /api
frontend/   SvelteKit: страницы, местечки, редактор
deploy/     скрипт развёртывания и конфиг nginx
bin/        запуск для разработки
```

## Разработка

Понадобятся Ruby 4.0.6 (например, через rbenv), Node.js 22+ и PostgreSQL 16+.

```bash
bin/setup   # зависимости, база и демо-местечки
bin/dev     # API на :3000, сайт на http://localhost:5173
```

Демо-вход: `niki@example.com` / `password123`. Зимние эффекты можно посмотреть в любое время: `/?season=winter` или `/?season=festive`.

Проверки:

```bash
cd backend && bin/rails test && bin/rubocop && bin/brakeman
cd frontend && npm run check && npm run lint && npm test
```

### Как это устроено

- Браузер работает с одним адресом: `/api/*` уходит в Rails (при разработке через прокси Vite, в продакшене через nginx). При серверном рендеринге SvelteKit сам ходит в Rails и передаёт cookie пользователя.
- Сессия хранится в подписанной httpOnly cookie с `SameSite=Lax`. Изменяющие запросы дополнительно проверяются по заголовку `Origin`.
- Профиль, тема и содержимое блоков лежат в JSONB. Перед сохранением данные проходят через схемы (`backend/lib/schema.rb`, `backend/app/models/block/kinds.rb`), которые отбрасывают лишнее, нормализуют значения и возвращают ошибки с путём до поля.
- Картинки уменьшаются в браузере перед загрузкой, поэтому libvips на сервере не нужен.
- Иконки технологий и брендов генерируются из simple-icons: `cd frontend && node scripts/icons.mjs`.
- Цитаты в подвале лежат в `frontend/src/lib/mottos.ts`.

## Развёртывание

Нужен сервер с Ubuntu Server 26.04, у которого домен и `www` уже смотрят на его IP.

```bash
git clone https://github.com/emostr/MySweetPlace.git
sudo MySweetPlace/deploy/deploy.sh --domain mysweetplace.org --email you@example.com
```

Скрипт:
- ставит пакеты, Node.js и Ruby (через rbenv);
- создаёт пользователя `mysweetplace` и базу PostgreSQL (вход по peer-аутентификации, без пароля);
- генерирует секреты и собирает приложение в `/srv/mysweetplace`;
- заводит systemd-сервисы `mysweetplace-backend`, `mysweetplace-frontend` и ежедневный таймер очистки загрузок;
- настраивает nginx и получает сертификат Let's Encrypt.

Повторный запуск той же командой обновляет приложение до свежего `master`.

- Настройки лежат в `/etc/mysweetplace/backend.env` и `frontend.env`: SMTP для писем восстановления пароля, принудительный сезон.
- Загруженные файлы хранятся в `/srv/mysweetplace/storage`.
- Логи: `journalctl -u mysweetplace-backend -f`.
- Дополнительные флаги: `--no-ssl`, `--firewall`, `--branch`, `--repo`, `--seed`.
